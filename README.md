# 4D Race

Live AI Fluency game for the Red Clay All Hands (Oct 22, 2026).

- **Players:** https://rcc610.github.io/4d-race/ (the QR code on the big screen points here)
- **Big screen (presenter only):** https://rcc610.github.io/4d-race/host.html

## Running the game
1. Open `host.html` on the presenting laptop and share that window in Teams.
2. Press **New game** once, then let people join. Team assignment is automatic.
3. Press **→** (or the red button) to start, reveal and move on. A round also closes by itself when the timer ends or everyone has answered.
4. Top players show after rounds 2, 4 and 6. Final results come after round 8.

Keys: `→` next, `F` full screen, `H` hide the control bar.

## Changing questions
Edit `common.js` (the `RACE` list). Live scores and answers are stored in the Firebase project `d-race-6001d` (Firestore).
